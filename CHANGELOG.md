# Changelog

## 0.1.0 — unreleased

First release.

- Tokens that read Claude's host style variables, with published light and dark fallbacks.
- Tailwind 4 mapping: semantic colour, type, radius and border utilities; default palette removed.
- Controls: Button, ButtonLink, TextLink, SegmentedControl, ToggleChips, InlineTabs, Switch, Slider, Stepper, SwatchRow.
- Display: Badge, DataList, Avatar, Thumbnail, Separator, 23 outline icons.
- States: Skeleton, StatusMessage, EmptyState, ErrorState.
- Layout: Stack, Row, Scroller.
- Storybook docs with theme, width, text size and host toggles.
- Lint rules and CI checks for floating UI, vertical scrolling, literal colours, tap targets, overflow at 320px and axe in both themes.
