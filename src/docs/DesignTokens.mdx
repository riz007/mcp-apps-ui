# Design tokens

Claude injects CSS custom properties into every MCP App. `tokens.css` reads them into `--mcp-*` properties, with the published values as fallbacks for hosts that send a partial set, and `theme.css` exposes those as Tailwind utilities. Nothing here redefines a host variable.

## Typography

`heading-*` utilities set size, line height and the emphasised weight together. Body text uses `text-xs` to `text-lg`. The default Tailwind size scale beyond `lg` is removed to keep to three levels.

## Accent

```css
:root {
  --mcp-accent: #c6613f;
  --mcp-accent-contrast: #ffffff;
}
```

The accent fills primary buttons and marks selection in `SegmentedControl`, `ToggleChips`, `InlineTabs`, `Switch` and `Slider`. It defaults to the host's primary text colour. Check the contrast of your pair in both themes; never use the accent for page backgrounds, body text or borders.

## Removed defaults

`theme.css` clears Tailwind's colour palette. `bg-white`, `text-gray-500` and friends don't exist, so a hardcoded colour can't sneak in through a utility class.
